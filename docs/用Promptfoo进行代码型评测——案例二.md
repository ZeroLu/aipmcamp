# 用Promptfoo进行代码型评测——案例二

## 模拟案例2——用户反馈分析
假设我们还是一个AI数学教育公司的产品经理，我们线上收到了大量的文本的用户反馈，我们希望用一个大模型来将这些用户反馈进行分类，节约我们的时间。

我们首先需要组建一批测试集，先回捞一些线上的数据，并人工进行分类：

接下来我们写一个提示词来尝试分类：
```
请将以下客户投诉归类为以下一个或多个类别：
软件故障、用户不熟悉操作、功能需求、服务中断。
只需回复分类结果。

投诉内容：{{complaint}}

分类：
```

然后我们把上一个案例中的promptfooconfig.yaml文件改名，然后创建一个新的promptfooconfig.yaml文件，并输入下面的内容：

```
description: 用户反馈分类

prompts:
  - name: 基础提示词
    raw: |
      请将以下客户投诉归类为以下一个或多个类别：
      软件故障、用户不熟悉操作、功能需求、服务中断。
      只需回复分类结果。

      投诉内容：{{complaint}}

      分类：

providers:
  - id: openai:chat:deepseek-chat  # Model name included in provider ID
    config:
      temperature: 1.0
      max_tokens: 4000
      apiKey: {{请输入你自己的DS API KEY}}
      apiHost: api.deepseek.com
      apiBasePath: /v1

tests: test_cases.csv

defaultTest:
  assert: 
    - type: contains-all # 确保输出包含标准答案中的所有内容
      value: '{{golden_answer}}'
```

运行后， 我们看下准确率有88.24%，其实挺高的。


我们可以优化一下提示词，加入一些示例，这样或许可以提高准确率。更新后的`promptfooconfig.yaml`如下：

```
description: 用户反馈分类

prompts:
  - name: 基础提示词
    raw: |
      请将以下客户投诉归类为以下一个或多个类别：
      软件故障、用户不熟悉操作、功能需求、服务中断。
      只需回复分类结果。

      投诉内容：{{complaint}}

      分类：
  - name: 带示例的提示词
    raw: |
      你是一名专注于AI数学解题App用户反馈归类的AI助手。你的任务是分析用户反馈，并将其归入以下一个或多个类别：

      1. 软件故障：与软件未按预期运行相关的问题。
      2. 用户不熟悉操作：因用户理解有误或误用导致的困难。
      3. 功能需求：对新功能或改进的建议。
      4. 服务中断：影响服务可用性的系统性问题。

      重要规则：
      - 一个投诉可能属于多个类别，如有多个请全部列出，但尽量优先选择最相关的单一类别。

      示例：
      1. 投诉内容：“拍照上传作业总是失败，还会卡死。”
      分类：软件故障

      2. 投诉内容：“我不会用错题本，怎么把错题加进去？”
      分类：用户不熟悉操作

      3. 投诉内容：“希望能加个导出全部错题的功能。”
      分类：功能需求

      4. 投诉内容：“APP一直显示‘服务器维护中’，进不去。”
      分类：服务中断

      5. 投诉内容：“用新版后题目加载不出来，而且经常提示维护。”
      分类：软件故障, 服务中断

      6. 投诉内容：“怎么老是算错答案啊，这APP靠谱吗？”
      分类：软件故障

      7. 投诉内容：“你们的错题本的按钮能不能做得明显一些，我经常找不到”
      分类：功能需求, 用户不熟悉操作

      现在请对下方客户投诉进行分类：

      <complaint>{{complaint}}</complaint>

      只需回复对应的类别，不要输出其他内容。
      分类：

providers:
  - id: openai:chat:deepseek-chat  # Model name included in provider ID
    config:
      temperature: 1.0
      max_tokens: 4000
      apiKey: sk-12bd10e5456f4e01b8ba3eb07a09d49e
      apiHost: api.deepseek.com
      apiBasePath: /v1

tests: test_cases.csv

defaultTest:
  assert: 
    - type: contains-all
      value: '{{golden_answer}}'

```
我们再次运行，新版提示词的准确率达到了100%！你也可以尝试写一些别的提示词，看下能否起到类似的作用。
