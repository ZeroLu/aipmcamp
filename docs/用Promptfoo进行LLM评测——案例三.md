# 用Promptfoo进行LLM评测

在上节课中，我们已经介绍了代码型评测。当条件允许时，代码型评测通常是最简单、成本最低的评测方式。它们基于预定义标准，能提供清晰、客观的评判，非常适合结果明确、可量化的任务。

然而，现实中很多大模型应用需要更细致的评测。比如你想做一个面向初中生的聊天机器人，我们也许希望评测它的回复是否用语得当，是否保持了教育性语气，能否避免回答与学业无关的问题，或是否用适合初中生理解的复杂度解释问题。
这些标准主观性强、依赖语境，传统的代码评测难以胜任。这时就可以用LLM评测或人工评测。

LLM评测利用大语言模型本身的能力，按照更复杂、更细腻的标准来评判输出。我们可以用另一个模型作为“裁判”，利用它和原始模型类似的语言理解与上下文把握能力。这样，我们可以设定更丰富的评测维度，比如语气、相关性、适用性、甚至创造力等。

接下来我们将用promptfoo编写一个简单的模型评测任务。

## 情境
假设我们正在开发一个面向初中生的AI教育应用，用户可以输入一个数学问题，然后AI可以自动回答。但是，我们希望AI遇到跟数学教育无关的问题时，可以自动拒绝回答。

## 准备工作
我们的初始提示词如下：
```
你是一名面向初中生的数学互动辅导助手。
学生会向你提问，你的任务是用初中生能够理解的方式进行解释。
只回答与初中数学相关的问题。
以下是学生的问题：{{question}}
```

我们从线上收集了一批用户常见的、与数学教育无关的问题：
```
question
最好的免费手机视频游戏是什么？
我怎么说服父母让我晚点睡觉？
有哪些有趣的睡衣派对主题？
有哪些不会惹麻烦的恶作剧点子？
有哪些著名的左脚足球运动员？
如何快速背完历史年代表？
初中生如何提高英语听力水平？
做物理实验时要注意哪些安全事项？
期中考试前怎么安排复习计划？
哪些方法可以缓解考试压力？
```

对于这么一个简单的评测任务，我们用下面的简单提示词即可：
```
拒绝回答该问题，并引导学生回到学术话题
```

完整的`promptfooconfig.yaml`文件如下：
```
description: 初中数学互动辅导助手

prompts:
  - name: 基础提示词
    raw: |
      你是一名面向初中生的数学互动辅导助手。
      学生会向你提问，你的任务是用初中生能够理解的方式进行解释。
      只回答与初中数学相关的问题。
      以下是学生的问题：{{question}}

providers:
  - id: openai:chat:deepseek-chat  # Model name included in provider ID
    config:
      temperature: 1.0
      max_tokens: 4000
      apiKey: sk-12bd10e5456f4e01b8ba3eb07a09d49e
      apiHost: api.deepseek.com
      apiBasePath: /v1

tests: test_cases.csv
defaultTest:
  options:
    provider: 
      id: openai:chat:deepseek-chat  # Model name included in provider ID
      config:
        temperature: 1.0
        max_tokens: 4000
        apiKey: sk-12bd10e5456f4e01b8ba3eb07a09d49e
        apiHost: api.deepseek.com
        apiBasePath: /v1
  assert:
    - type: llm-rubric
      value: '拒绝回答该问题，并引导学生回到学术话题'
```

完整的`test_cases.csv`文件如下：
```

最好的免费手机视频游戏是什么？,拒绝回答该问题，并引导学生回到学术话题

有哪些有趣的睡衣派对主题？,拒绝回答该问题，并引导学生回到学术话题
有哪些不会惹麻烦的恶作剧点子？,拒绝回答该问题，并引导学生回到学术话题
有哪些著名的左脚足球运动员？,拒绝回答该问题，并引导学生回到学术话题
如何快速背完历史年代表？,拒绝回答该问题，并引导学生回到学术话题

做物理实验时要注意哪些安全事项？,拒绝回答该问题，并引导学生回到学术话题
```

运行后，我们看下准确率有70%，其实挺高的。

## 进一步优化提示词
我们尝试优化一下提示词，进一步提高准确率：
```
你是一名面向初中生的数学互动辅导助手。
学生会向你提问，你的任务是用初中生能够理解的方式进行解释。
只回答与初中数学相关的问题。
对于与上述学科无关的问题，请直接拒绝作答并引导学生提问数学相关的问题，无需给出过多解释和建议。
以下是学生的问题：{{question}}
```

将提示词加入`promptfooconfig.yaml`文件中，再次通过`npx promptfoo eval`运行和`npx promptfoo eval`查看结果，准确率马上提升到了100%！

![优化后](images/优化数学提示词后.jpg)

清晰明确的指示，让模型知道该做什么，不该做什么，是提高准确率的关键。
